## Downloads und Hilfe

Die Anleitung jeder Anwendung enthält Voraussetzungen und erste Schritte. Laden Sie die Anwendung aus Releases herunter, nicht das Quellcode-ZIP. Preview-Versionen werden noch entwickelt; Projekte mit dem Status „Nur Quellcode“ haben kein fertiges Installationspaket.

Für Fragen oder Fehlerberichte nutzen Sie „Fehler melden“ in der Zeile der Anwendung. Geben Sie die Programmversion, das Betriebssystem und die Schritte zum Nachstellen an.

### Technologien

C# · Python · Swift · WPF · PySide6 · .NET · [JavaScript — Quick Answer](https://popovantondev.github.io/QuickAnswer/index.html) · SwiftUI · Ruby · AppKit · PowerShell · Rust · egui · SQLite

Vor der Nutzung die Anleitung und Release-Hinweise lesen.
